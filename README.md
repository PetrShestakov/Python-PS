## 📖 About / О проекте

**EN:** A personal collection of beginner-friendly programming exercises. Topics include Python lists, sets, loops, conditions, basic mathematics, dates and random numbers. The repository also contains a small HTML/JavaScript deposit calculator.

**RU:** Личная коллекция учебных задач по программированию. Темы: списки и множества Python, циклы, условия, базовая математика, даты и случайные числа. Также здесь есть небольшой калькулятор банковского вклада на HTML/JavaScript.

## ▶️ Getting Started / Запуск

**EN:** Install Python 3, clone the repository and run an individual exercise.

**RU:** Установите Python 3, клонируйте репозиторий и запустите отдельное упражнение.

```bash
git clone https://github.com/PetrShestakov/Python-PS.git
cd Python-PS
python lesson2.py
```

**EN:** Open `calc.html` in a browser to try the deposit calculator.

**RU:** Для запуска калькулятора откройте `calc.html` в браузере.

> **Note / Примечание:** These are learning materials rather than a finished application. Some scripts are incomplete or contain bugs. / Это учебные материалы, а не готовое приложение. В отдельных скриптах есть незавершённые фрагменты и ошибки.
